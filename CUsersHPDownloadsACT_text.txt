1. What Is This Project?
This is an AI-powered ACT exam preparation platform. It works like a personal tutor app that students use daily to practice ACT questions, get AI explanations for wrong answers, and track their progress toward a target ACT score — all behind a monthly or annual subscription.
The platform includes four key experiences:
A student signs up, pays via Stripe, and takes a diagnostic test to establish their starting ACT score.
Every day, the app generates a personalized “quest” — a set of 20 practice questions tailored to their weaknesses.
An AI tutor explains mistakes in real time on an interactive whiteboard/canvas.
As the student improves, questions automatically get harder. Streaks, XP, and badges keep them motivated.

5. Your Tasks (What You Need to Build)
Task 1 — Switch Everything from SAT to ACT
The entire platform was built for SAT. You must change all content, scoring, and subjects to ACT.
Change subjects: English (75 Qs), Math (60 Qs), Reading (40 Qs), Science (40 Qs)
Change scoring: ACT scores 1–36 composite (not 400–1600)
Replace all SAT question taxonomy with ACT taxonomy
Change all text labels, branding, and copy from SAT to ACT
Create a new actTopics.ts file listing all ACT subjects and subtopics
Task 2 — Build the Database
Create all Supabase tables using Drizzle ORM. Key tables needed:
users — id, email, name, target_score, current_score, streak, xp
questions — id, subject, topic, subtopic, difficulty, question_text, options, correct_answer, explanation
quests — id, user_id, date, questions_list, completed, score
skill_mastery — id, user_id, topic, mastery_level, accuracy, total_attempts
subscriptions — id, user_id, stripe_customer_id, plan, status, trial_end
Task 3 — Connect Login and Signup (Clerk)
Set up Clerk project and add API keys to .env
Wrap layout with ClerkProvider
Add sign-in and sign-up pages using Clerk components
Protect all authenticated routes using auth()
Auto-create user row in database on first signup
Task 4 — Seed the Question Bank
Write or AI-generate 20–30 practice questions per ACT topic
Each question needs: question text, 4 options, correct answer, difficulty (1–10), explanation
Write a script to bulk-insert questions into Supabase
Task 5 — Build the Daily Quest System
Create API route: /api/quest/generate
If today's quest exists for this user, return it
If not, pick 20 questions: 60% weakest topics, 30% mid-level, 10% stretch
Save the quest to the quests table
Return questions to the frontend
Task 6 — Build Score Tracking
Create API route: /api/quest/complete
Receive student answers after quest completion
Calculate correct answers per ACT section
Convert to 1–36 scale using ACT score tables
Calculate composite score (average of four sections)
Update skill mastery levels in database
Save score history for progress charts
Task 7 — Set Up Stripe Payments
Create Stripe products: Monthly Plan and Annual Plan
Build checkout page with Stripe Checkout Session
Build webhook endpoint: /api/stripe/webhook
On payment success: activate subscription in database
On payment failure: mark subscription inactive, lock access
On cancellation: update subscription status
Add middleware to gate premium features
Build billing portal for users to manage their subscription
Task 8 — Build Notifications
Use Resend (email) for daily reminders, streak alerts, weekly summaries
Use OneSignal or web push for browser notifications
Set up daily cron job to send reminders at each user’s scheduled study time
Build missed session detection and practice lock/reset flow
Task 9 — Build Gamification
XP system: Easy correct = +10 XP, Medium = +20 XP, Hard = +30 XP
Streak system: Complete a quest daily to increment; miss a day to reset
Tier system by ACT score: Bronze (1–15), Silver (16–20), Gold (21–25), Platinum (26–30), Diamond (31–36)
Achievement badges for milestones
Level-up and score milestone animations using Framer Motion
Task 10 — Connect UI to Real Data
Home dashboard: wire real score, streak, and today’s quest
Progress screen: fetch score history, display with Recharts
Profile screen: wire real XP, badges, and study time
Mentor screen: wire real study calendar and schedule
Match all screens pixel-perfectly to the provided design mockups
Task 11 — Integrate the Canvas
Import the AI tutor canvas as a component
When student starts daily quest, open canvas with their questions
When quest finishes, send results back to /api/quest/complete
Task 12 — Testing
Test full signup → payment → quest → score update flow end to end
Use Stripe test card numbers to simulate payments
Verify score math is correct across all four ACT sections
Test adaptive difficulty: questions get harder as student improves
Test notifications send at correct times
Test on mobile and desktop
Write automated end-to-end test suite before delivery
